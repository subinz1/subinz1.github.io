# Portfolio interface system

## Direction

- **Personality:** Exact, evidence-led, quietly technical
- **World:** An engineering dossier for ML infrastructure work: durable records, readable signal paths, and clear ownership
- **Focal moment:** The CRCR production-path trace in the hero
- **Signature:** Small teal status markers identify verified paths, selected records, and active navigation

## Foundations

- **Spacing base:** 4px
- **Scale:** 4, 8, 12, 16, 24, 32, 48, 64, 96, 128
- **Layout:** Content max-width 1216px; desktop page edge 32px; mobile page edge 20px
- **Depth:** Surface steps and one-pixel hairlines; no colored glows or decorative shadows
- **Radius:** Controls 6px, cards 10px, panels 14px

## Color

- **Dark neutral ramp:** #0b0d14, #11141c, #171b25
- **Light neutral ramp:** #f5f7fa, #ffffff, #eceff4
- **Primary text:** #eef0f5 dark / #111827 light
- **Secondary text:** #a3a9b8 dark / #4b5565 light
- **Accent:** Teal (#70d1bb dark / #087c55 light), reserved for verified paths, selected states, and primary actions
- **Semantic colors:** Green and red only when they communicate status

## Components

- **Navigation:** 36px dense rows; active state uses an underline and status marker
- **Buttons:** 40px compact controls, 44px primary action; 6px radius
- **Cards:** 10px radius, 20px padding, surface background, 1px hairline; hover changes surface and border only
- **Metadata:** Monospace, 12px, sentence case, restrained tracking
- **Motion:** 160ms for controls, 380ms for entrances; opacity and transform only; all motion respects reduced-motion preferences
